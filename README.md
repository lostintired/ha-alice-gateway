# Alice gateway

Репозиторий приложений Home Assistant с одним приложением — `alice_gateway`.
Это nginx-фильтр перед HA для Yandex Smart Home. Снаружи он пропускает только белый список
«метод + путь», на всё остальное отвечает пустым 403.

Схема: интернет → облачный режим CrazeDNS роутера Netcraze/Keenetic (TLS на роутере, опция
`x-real-ip`) → фильтр на порту `8090` → HA на `127.0.0.1:80`.

## Установка

«Настройки» → «Приложения» → «Магазин» → «Репозитории» → `https://github.com/lostintired/ha-alice-gateway`.

У приложения нет доступа к API HA и Supervisor, к папкам HA и к токенам. Команды оно получает
только через `stdin`.

## Опции

| Опция | Значение |
| --- | --- |
| `mode` | `probe` — зонд: на всё пустой 403, в журнал пишутся заголовки адреса клиента, HA не проксируется. `gateway` — рабочий фильтр |
| `public_host` | Публичное имя поддомена. Уходит в HA как `Host` и `X-Forwarded-Host`. Обязательно для `gateway` |
| `linking_minutes` | Через сколько минут окно привязки закрывается само (1–60, по умолчанию 15) |
| `extra_paths` | Дополнительные адреса: `path` — точный путь или префикс со `*` в конце, `methods` — методы через запятую |

Пример `extra_paths`:

```yaml
- path: /api/webhook/<идентификатор>
  methods: POST
```

## Что пропускается

- `HEAD|GET /api/yandex_smart_home/v1.0`, `GET …/v1.0/ping`, `GET …/v1.0/user/devices`,
  `POST …/v1.0/user/devices/query`, `POST …/v1.0/user/devices/action`, `POST …/v1.0/user/unlink`;
- `POST /auth/token`;
- адреса из `extra_paths`;
- при открытом окне привязки — адреса из `alice_gateway/nginx/window.map` (страница входа HA).

Сверка идёт по сырому пути запроса с учётом регистра. Не проходят `%`, `\`, `;`, `//`, сегменты `.`
и `..`, строка запроса у постоянных адресов, `Upgrade`, схема клиента не `https` и запросы не от роутера
`192.168.1.1`.

Адрес клиента берётся только из `X-Real-IP` от роутера. В HA уходит один `X-Forwarded-For`; частные,
loopback и link-local адреса заменяются заглушкой `198.51.100.1`.

## Окно привязки

Команды через `stdin`: `open` открывает окно на `linking_minutes` минут, `close` закрывает.
После запуска приложения окно всегда закрыто. Из HA:

```yaml
action: hassio.app_stdin
data:
  app: <slug приложения>
  input: open
```

## Проверка

`python check.py --offline` собирает образ в Docker и проверяет белый список, обходы путей, окно,
`extra_paths`, заголовки для HA и журнал. `python check.py --url https://<поддомен>` выполняет те же
запросы снаружи. Ожидается, что `ping` отвечает 200 `Yandex Smart Home`: интеграция Yandex Smart
Home уже добавлена в HA.

Изнутри дома имя поддомена обычно ведёт на сам роутер, мимо облака. Чтобы проверить путь через
облако, добавьте `--connect <IP>` — адрес из публичного DNS (`nslookup <поддомен> 8.8.8.8`).
Соединение пойдёт на этот адрес, а имя в TLS и `Host` останется поддоменом.

Секретов, адресов вебхуков и имён доменов в репозитории нет.
