# Alice gateway

Репозиторий приложений Home Assistant с одним приложением — `alice_gateway`.
Это nginx-фильтр перед HA: снаружи пропускает только пути Yandex Smart Home, на остальное — пустой 403.

Сейчас доступен только режим `probe`: на любой запрос пустой 403, в журнал приложения пишутся
заголовки адреса клиента. HA в этом режиме не проксируется.

Установка: «Настройки» → «Приложения» → «Магазин» → «Репозитории» →
`https://github.com/lostintired/ha-alice-gateway`.

Секретов, адресов вебхуков и имён доменов в репозитории нет.
